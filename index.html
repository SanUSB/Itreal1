Itreal: Immersive technologies for augmented and virtual reality
(Dynamic Repository and IoT AR tool)

A realidade aumentada é uma tecnologia que possibilita a sobreposição e a interação de animações e imagens 3D no mundo real através de dispositivos computacionais como smartphones. O ambiente Itreal (Immersive Technologies for Augmented and Virtual Reality) é uma ferramenta IoT educacional simples e gratuita de introdução à realidade aumentada livre para crianças, jovens e adultos sem a necessidade de saber programação, utilizando navegadores Web convencionais como Google Chrome ou Mozilla Firefox e sem a necessidade de instalar aplicativos. É possível acessar palestras na íntegra sobre teoria e aplicação prática interdisciplinar de realidade aumentada clicando nos links https://youtu.be/Xf04qNoc3Sw e https://youtu.be/wyWV5FyVx8A. Para modificar a dimensão ou escala inicial da imagem 3D projetada em realidade aumentada, basta seguir as intruções em https://youtu.be/eZpQBgZcXTM. O grupo de pesquisa @grepet_publicacoes disponibliza o uso livre e gratuito dessa ferramenta. Augmented reality is a technology that enables the overlay and interaction of animations and 3D images in the real world through computing devices such as smartphones. The Itreal environment (Immersive Technologies for Augmented and Virtual Reality) is a simple and free educational IoT tool for introducing open augmented reality to children, youth, and adults without the need for programming knowledge, using conventional Web browsers like Google Chrome or Mozilla Firefox and without the need to install apps. You can access full lectures on theory and interdisciplinary practical application of augmented reality by clicking the links https://youtu.be/Xf04qNoc3Sw and https://youtu.be/wyWV5FyVx8A. To modify the initial dimension or scale of the 3D image projected in augmented reality, just follow the instructions at https://youtu.be/eZpQBgZcXTM. The research group @grepet_publicacoes makes the free use of this tool available.

A Solução DinâmicaThe Dynamic Solution

Para manipular de forma dinâmica uma imagem 3D de realidade aumentada com os dedos pela tela do smartphone, basta adicionar abaixo um endereço URL ou fazer o upload um de uma imagem .glb (Graphics Library Binary) que pode ser gerada por programas gráficos como Tinkercad, ou encontradas livremente em diversos repositórios na nuvem como Sketchfab, entre outros sites e repositórios como o dynamicrepo do Itreal que, como mostrado no vídeo tutorial em Tutorial 1 e em Tutorial 2, possibilita tanto utilizar o endereço URL já existente como também baixar o arquivo .glb e fazer o upload no novo perfil para criar aplicações de realidade aumentada com smartphones. To dynamically manipulate a 3D augmented reality image with your fingers on the smartphone screen, simply add a URL address below or upload a .glb (Graphics Library Binary) image that can be generated by graphic programs such as Tinkercad, or freely found in various cloud repositories like Sketchfab, among other sites and repositories such as Itreal's dynamicrepo which, as shown in the tutorial video at Tutorial 1 and at Tutorial 2, allows both using an existing URL address and downloading the .glb file to upload to the new profile to create augmented reality applications with smartphones.

Como Funciona?How it works?

O arquivo glb é gerado pela compilação em um arquivo único da pasta de arquivos gltf (Graphics Library Transmission Format) e suas bibliotecas de textura. O gltf é um formato de arquivo para imagens e modelos 3D de realidade aumentada em navegadores WEB. Para compilar rapidamente gltf em glb basta acessar o makeglb e seguir as instruções em Vídeo explicativo. The glb file is generated by compiling the gltf (Graphics Library Transmission Format) file folder and its texture libraries into a single file. Gltf is a file format for images and 3D models of augmented reality in WEB browsers. To quickly compile gltf into glb just access makeglb and follow the instructions at Explanation Video.
